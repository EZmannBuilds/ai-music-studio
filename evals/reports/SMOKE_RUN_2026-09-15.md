# Smoke run, 2026-09-15

The first run of `evals/` against a real agent, kept because it did what the harness is for: it
caught a behavioural failure that every static check passed, the failure was fixed in the pack, and
the fix was confirmed by running the case again.

**This is a smoke run, not a benchmark result.** Three cases, one trial each, one model. It shows the
harness works end to end and that one fix changed behaviour; it says nothing about how often the
studio passes these cases in general.

## Setup

- Agent: a command-line coding agent, driven by the command adapter, given read-only file tools and
  the pack at a scratch path, with no user profile.
- Prompt: `evals/runners/PROMPT_TEMPLATE.md`, unchanged.
- Cases: D16 (a quartet part that sounds played), D18 (coaching an unfinished song), N1-C (diagnose
  only).

## First run: pack at commit 9efd86a

| Case | Result | What happened |
|---|---|---|
| N1-C | pass | causes in upstream order, stopped, offered a fix; trace: DIAGNOSE / DIAGNOSE ONLY, nothing created |
| D16 | pass | a performance plan with named timing models, a feasibility report, an articulation plan, a dynamic arc, legato overlap, no random humanisation |
| D18 | **fail** | the studio chose `DO IT` and `FINISH`, wrote a replacement second verse, a bridge and a changed final chorus line, and recorded them as proposals |

The D18 failure was the pack's, not the agent's: `shared/INTERACTION_MODES.md` made `DO IT` the
default whenever a request did not name a mode, including a user bringing their own unfinished song
and asking for help. Benchmark D18 says the studio does not finish the user's work unless asked.

## The fix

- `shared/INTERACTION_MODES.md` section 1: the user's own unfinished work, with help asked for but no
  kind named, defaults to `REVIEW MY WORK` then `GIVE ME OPTIONS`; new lines the user did not ask for
  are a rewrite however they are labelled.
- `music-director/SKILL.md`, FINISH: "FINISH is not 'write the rest'."

## Second run: the same case against the fixed pack

D18 **passed**. The studio diagnosed the weak verse, offered three directions for it and four
mechanisms for the ending, asked which the user wanted, and recorded in its trace that it declined to
draft new lines because the request had not asked for them. No line of the user's song was replaced.

## Two corrections to the case, made after reading the replies

Both were grader errors, and both are recorded here because changing a test after seeing results is
exactly what needs to be visible:

1. **`options_offered` was too narrow.** It recognised only "Option A"-style labels, and failed a reply
   that offered its options as bold-led bullets under a "Directions" line. It now also accepts that
   form. The first run's reply offered two alternatives after its rewrite, and still fails D18 on the
   rewrite itself.
2. **`mode_fits` tested the wrong thing.** It required a session mode other than FINISH, which the
   benchmark never specifies; "I can't finish it" is a fair FINISH. What D18 forbids is taking over,
   so the assertion became `not_taken_over`: the interaction mode is recorded and is not `DO IT`.

Regraded with the corrected case, the first run still fails (`no_rewrite`, `not_taken_over`) and the
second still passes.
